# Contributing

Thanks for helping improve DSH Desktop.

## Development

1. Install Node.js 24 or later.
2. Run `npm.cmd install`.
3. Run `npm.cmd start` to test the launcher with a locally installed DeepSeek Harness.
4. Run `npm.cmd run lint` before opening a pull request.

## Pull requests

Keep each pull request focused, explain the user-visible change, and do not commit generated files from `node_modules/` or `dist/`. Never include `.dsh` configuration, credentials, sessions, or logs.
