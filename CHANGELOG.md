# Changelog

## 0.2.0

- Add a Chinese GUI installation center shown before installation.
- Offer independent web-only and desktop installation with per-user shortcuts.
- Bundle Node.js, npm, official DeepSeek Harness and frontend assets.
- Add API Key setup through the official local credential API, shared by both modes.
- Link to the DeepSeek developer platform, API Key page and Chinese API documentation.
- Support official launch-token authentication, loopback binding, retry and port conflicts.
- Isolate desktop data from existing CLI Harness profiles.
- Add fixture installation tests, hidden GUI tests, native-module checks and real Harness configuration tests.
- Build a self-extracting installer with checksum artifacts and draft release automation.

## 0.1.0

- Initial desktop wrapper requiring a separately installed Harness.
