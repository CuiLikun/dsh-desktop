还没有 API KEY？

三步获取密钥

  1. 登录开放平台

    使用你的 DeepSeek 账号登录。

  2. 创建 API Key

    进入 API Keys 页面，创建并复制密钥。

  3. 粘贴并保存

    将密钥粘贴到左侧。实际调用需要可用额度。

A LITTLE HELP

从安装到第一条对话。

不需要命令行。按下面的步骤开始。

第一次使用

  1. 在安装总览选择 Web 版或桌面版，点击一键安装。
  2. 在 API 配置中填写 Key，点击保存并一键配置。
  3. 点击启动，在 Harness 中选择 Choose workspace，添加项目文件夹。
  4. 新建会话，告诉 DeepSeek 你想完成什么。

如何停止与卸载？

Web 版可从开始菜单运行“停止 DeepSeek Harness Web”；桌面版从托盘菜单退出。安装文件按版本保存在本地 Programs/DSH Web 或 Programs/DSH Desktop 中，停止后可以手动删除对应版本目录与快捷方式。配置数据默认保留。

API 已保存，但无法对话？

保存配置不会验证账户余额或调用模型。请检查 Key 是否有效、账户额度和网络连接，也可在 Harness 的 Settings → Models 中查看配置。
